## ⚡ Overview

**THE BLOCK** is a high-energy landing page for a modern cultural athletic club that fuses high-performance running with avant-garde streetwear and community dinner culture.

Designed as a third space away from corporate isolation and traditional gym gatekeeping, THE BLOCK integrates:
- **The Runners**: Dawn tempos, coached intervals, and non-elitist pacing.
- **The Makers**: In-house apparel prototyping and screen-printing lab.
- **The Table**: Communal Sunday dinners, handmade pasta, and life celebrations.

---

## 🚀 Key Features

1. **Cadence Audio Engine (Web Audio API)**:
   - Procedural 168 BPM runner cadence synthesizer (808 sub-kick + high-frequency stride metronome).
   - Real-time animated equalizer bars with tactile sound effects.

2. **Run Division & Interactive Route Telemetry**:
   - HTML5 Canvas simulation of 3 signature routes (*Riverside Drift 8.2M*, *Midnight Crit 5.0M*, *East Bridge Repeats 6.5M*).
   - Animated runner waypoint tracker along the course.
   - Interactive Pace Slider (5:30/mi to 10:30/mi) calculating duration, energy burn, and squad heat assignment (*Heat 1 Speedpack*, *Heat 2 Tempo*, *Heat 3 Social*).

3. **FW26 Capsule Drop Atelier**:
   - High-fashion technical running apparel lookbook.
   - Live drop countdown timer.
   - Interactive specification modals with colorway details and size selection (XS–XL).

4. **Filterable Schedule & Calendar Sync**:
   - Event filter pills (*All*, *Runs*, *Drops*, *Gatherings*).
   - Interactive RSVP modal that generates a real `.ics` calendar invite for Apple/Google Calendar.

5. **Athlete Pass Studio**:
   - Real-time personalized digital member credential generator.
   - Custom SVG barcode, dynamic `#BLK-23-XXXX` member ID, and 1-click **Download Official Pass (.PNG)** export via Canvas.
